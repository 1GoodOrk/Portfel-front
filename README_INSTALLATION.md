# Installation

## Programs installation

- Nodejs: node-v24.22.0-x64
- Mongo: mongosh-2.13.0-x64
- VsCode: VSCodeUserSetup-x64-1.141.2

Check:

```bash
  node -v
  npm -v
```

## Allow scripts

```bash
  Set-ExecutionPolicy unrestricted
```

## Package installation

Front

```bash
  npm install --legacy-peer-deps
```

Back

```bash
  npm install
```
